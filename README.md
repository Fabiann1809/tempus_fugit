# Tempus Fugit

Aplicación de escritorio desarrollada en Python con Tkinter que combina un reloj analógico y digital en una interfaz de estética vintage (madera y dorado). Incluye cuatro módulos accesibles por pestañas: **Reloj**, con ajuste manual de hora arrastrando las manecillas o mediante spinboxes; **Cronómetro**, con registro de vueltas; **Alarma**, que suena en bucle hasta ser silenciada mediante un banner flotante; y **Cuenta regresiva**, configurable por el usuario. Para ejecutarla basta con correr `python main.py`.
